# Project Specification: Autonomous Shopping Research & Price Tracking Agent
## 1. ObjectiveBuild a Python-based AI agent using **LangGraph** and **LangChain** that acts as a conversational shopping assistant. The user will ask the assistant to find the best product on the market for a given need, discuss and refine options across multiple turns, and finalize a single winning product. Once finalized, the agent locates live retail listings, confirms a target price threshold with the user, adds the product to a price-tracking watchlist, and runs a background monitor that notifies the user when the price drops.
**Hard Constraint:** The agent must NEVER execute purchases, handle payment details, or add items to shopping carts.
---
## 2. Tech Stack & Dependencies* **Language:** Python 3.11+* **Orchestration:** `langgraph` (with `SqliteSaver` for conversational checkpointing)* **LLM & Extraction:** `langchain`, `langchain-anthropic` (or `langchain-openai`), `pydantic` v2* **Graph 1 Web Search:** `tavily-python` (for product/review discovery and live retailer URL lookup)* **Graph 2 Web Scraping:** `crawl4ai` (free, open-source headless browser crawler with `JsonCssExtractionStrategy` and `schema.org` JSON-LD parsing for deterministic local price scraping)* **Database:** SQLite via `SQLAlchemy` or `sqlite3` (for tracked watchlist items and price history)* **Scheduler:** `APScheduler` (for periodic background price checks)* **Notifications:** Modular alert handler supporting **Console**, **Webhook (Discord/Slack/Telegram)**, or **Email (Resend/SMTP)*** **Interface:** Interactive CLI loop (cleanly decoupled from the graphs so a web UI or API can be attached later)
---
## 3. Core Architecture (Two-Graph Design)
### Graph 1: Interactive Research & Finalization Graph (Powered by Tavily)1. **`understand_intent` Node (Router):**   * Inspects the conversation history and latest user message to route to:     - `explore_or_refine`: User is starting a product search, asking follow-up questions, or narrowing requirements (budget, specs, use case).     - `finalize_product`: User explicitly selects a winning product to track (e.g., *"Let's go with the Sony WH-1000XM5"* or *"I've decided on Option 2"*).2. **`research_and_compare` Node:**   * Uses **Tavily Search** (`tavily-python`) to gather top product candidates and independent reviews (e.g., Wirecutter, RTINGS, Reddit) matching the user's current criteria.   * Uses LLM structured output (`with_structured_output`) to synthesize 3–4 `ProductCandidate` objects.   * Presents a clear side-by-side comparison (key specs, pros, cons, typical price range) and asks helpful follow-up questions to help the user narrow down their choice.   * *Loops back to user input* across as many turns as needed until the user finalizes a product.3. **`locate_retail_listings` Node (Triggered on `finalize_product`):**   * Uses **Tavily Search** targeted at major Canadian retailers (Amazon.ca, Best Buy Canada, official brand stores) to fetch exact direct product URLs and current live prices for the finalized model.4. **`confirm_tracking_terms` Node (LangGraph `interrupt`):**   * Pauses graph execution and displays the live retail listing(s) and current price found for the finalized product.   * Asks the user to confirm:     1. Which retailer listing(s) to monitor.     2. Their target alert price (suggesting a default of 10% below the current price if the user doesn't specify one).5. **`save_to_watchlist` Node:**   * Saves the finalized product, exact retailer URL(s), initial baseline price, and target alert price into the SQLite `tracked_items` table.   * Confirms to the user that background price monitoring is active.
---
### Graph 2: Scheduled Price Monitor Graph (Powered by Crawl4AI)*Runs automatically every 6 hours via `APScheduler` (and can also be triggered manually from the CLI).*1. **`fetch_active_trackers` Node:**   * Queries SQLite for all items in `tracked_items` with `status == "active"`.2. **`scrape_current_prices` Node (Deterministic Python + Crawl4AI — NO LLM tokens used):**   * Uses **`crawl4ai` (`AsyncWebCrawler`)** with headless Chromium to render each tracked retailer URL.   * Extracts structured price and stock status deterministically via embedded `application/ld+json` (`schema.org/Product` / `Offer`) tags first, falling back to `Crawl4AI`'s CSS/regex price extraction strategies.   * Logs a timestamped record into `price_history` and updates `lowest_price_seen` if applicable.3. **`evaluate_drops` Conditional Edge:**   * Evaluates whether `current_price <= target_price` OR `current_price < lowest_price_seen` (while `in_stock == True` and `current_price < last_notified_price`).   * If **False**: Ends execution silently without invoking an LLM.   * If **True**: Routes to `generate_and_send_alert`.4. **`generate_and_send_alert` Node:**   * Uses an LLM to generate a crisp deal alert (product name, retailer, old vs. new price, % discount, historical low context, and direct link).   * Dispatches the alert via the configured notification channel and updates `last_notified_price` in SQLite to prevent duplicate alerts.

## 4. Data Models (Pydantic & SQLite Schema)
### Pydantic Schemas```pythonfrom pydantic import BaseModel, Fieldfrom typing import List, Optional
class ProductCandidate(BaseModel):    name: str    brand: str    estimated_price: float    currency: str = "CAD"    rating_summary: str    key_specs: List[str]    pros: List[str]    cons: List[str]    best_for: str
class ResearchComparison(BaseModel):    candidates: List[ProductCandidate]    recommendation_summary: str    clarifying_question: Optional[str] = None
class RetailListing(BaseModel):    product_name: str    retailer: str    url: str    current_price: float    currency: str = "CAD"    in_stock: bool = True
class ScrapedPriceResult(BaseModel):    url: str    current_price: Optional[float] = None    currency: str = "CAD"    in_stock: bool = False    extraction_method: str  # e.g., "json-ld", "css-fallback", "failed"    error: Optional[str] = None```
### SQLite Database Tables1. **`tracked_items`**:   * `id` (PK)   * `product_name` (TEXT)   * `retailer` (TEXT)   * `url` (TEXT)   * `currency` (TEXT, default `"CAD"`)   * `initial_price` (REAL)   * `target_price` (REAL)   * `lowest_price_seen` (REAL)   * `last_notified_price` (REAL, nullable)   * `status` (TEXT: `"active"` | `"paused"`)   * `created_at` (DATETIME)2. **`price_history`**:   * `id` (PK)   * `item_id` (FK -> `tracked_items.id`)   * `price` (REAL)   * `in_stock` (BOOLEAN)   * `checked_at` (DATETIME)
